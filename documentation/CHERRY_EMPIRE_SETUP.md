
# Cherry Empire
Second game under Fruity Paradice. Built from main after Apple Catcher.
## Rules and economy
- First tree is mature and grows one fruit every 30 seconds. Harvesting a ripe fruit initially gives one cherry.
- Buy an additional tree with cherries (80 for tree two; rising price). Tree two takes 10 minutes to mature; later trees take an additional 10 minutes each. Initial cap: 12 trees.
- Each tree has fruit speed, cherry yield, auto harvester, capacity, and permanent Star Coin chance and multiplier upgrades. Auto harvesters begin at one harvest every two minutes, improving with upgrades. Only nonempty harvests count. Manual harvest collects all ripe fruit on that tree; harvest-all counts each nonempty tree once.
- Max speed, yield, auto harvester and capacity before prestige; prestige costs cherries, resets speed/yield/auto/capacity and sends that tree back into a growing stage, initially three minutes, increasing by three minutes each prestige. Fruit interval grows with prestige, caps rise, and base yield increases. Prestige cap: 20. Both permanent Star Coin levels are preserved. Chance starts at 0.1% per successful growth cycle, increases by 0.15 percentage points per level up to 10%, then approaches 100% with diminishing marginal gains. Both upgrades have no gameplay level cap. Stars on trees go into the existing wallet on harvest. No retroactive bonus on old fruit.
- Secret: Cheribelle rolls 1/100 per nonempty harvest after a second tree is planted; Fruiter rolls exactly 1/20,000 per nonempty harvest, independent of fruit count. Automatic offline harvests count individually. Ownership is shared with Apple Catcher, and the account receives each axolotl once.
## Saving / offline / security
- Server timestamps are authoritative. Fruit and auto harvest event counts are derived arithmetically from Date.now, not timers or per-fruit loops. No arbitrary offline-duration limit. Closed tabs send no requests. Browser estimates fruit and cherries locally; server settles Star Coins and secrets at next sync/action. Visible tabs sync once per minute plus user actions; hidden tabs do not poll.
- Existing live Worker, Firebase verification, privateGames document, account wallet and axolotl rules reused. Atomic Firestore commits use state preconditions, revision and request ID to avoid duplicate purchases or awards on retry, and concurrent wallet increments. Client never submits balances, clock or harvest quantities.
- Existing Firestore rules on main already cover this game. No new rule, paid service, scheduled job, secret or Worker is required.
- Run `node --test workers/cd-store/tests/cherry-empire.test.mjs`; deploy updated existing Worker with `cd workers/cd-store && npx wrangler deploy --config wrangler.live.toml`. Test on preview with verified Live Firebase account. Live browser, actual Firestore commits and production quota usage remain unverified.

- Capacity is 10 fruit initially, +10 per capacity upgrade and +5 per prestige; upgrade starts at 10 cherries with a rising cost. When full, new fruit (including possible Star Coins) cannot accumulate until a harvest; automatic harvests respect capacity during offline periods. Existing saved over-cap fruit is preserved and can be harvested. Old trees default to capacity level zero. Cherry Garden Mastery is awarded once when all twelve trees are prestige 3 or higher, using the existing trophies collection and toast.

- Yield upgrades grow 1 + yield level individual fruits each growth cycle, using one capacity slot per fruit. Prestige multiplies cherries per occupied slot by 1 + 2 × prestige, without increasing occupancy. Partial growth fills remaining slots; overflow is not stored. Star Coin rolls remain per successful growth cycle, and collectible rolls remain per nonempty harvest. Version 3 migrates earlier ripe fruit using its saved cherry value and preserves all previously earned value and stars. Automatic offline harvesting computes capacity for both possible interval arrival counts, without looping over elapsed time.

- Star Coin multiplier payout starts at 100%; each level adds a gradually diminishing percentage bonus using 1 + 2.5 × ln(1 + level/50). The first level pays about 104.95%. Chance pricing preserves the original first ten levels, then follows a quadratic curve instead of exponential costs; multiplier starts at 150 cherries and scales as 150 × (level+1)^1.7. Both are per tree, permanent, and optional for prestige. Successful Star Coin growth uses the multiplier at the time fruit grows. Fixed-point millionths are saved on the tree until harvest, then carried across all trees and harvests in the account orchard. Only whole coins are atomically credited to the existing wallet. Existing saved fruit/whole coins remain intact; version 4 defaults new multiplier levels and fractions to zero. Number precision and attainable cherry balances still bound practical progression.

- Cherry Empire has a fullscreen toggle with a full-window fallback. The orchard uses the full display width and scrolls vertically; summary and actions stay pinned on larger screens. Small screens can scroll the summary as well. Existing notifications remain inside the fullscreen view. No changes to reward logic or database rules.
