
# The Giving Tree
Fourth Fruity Paradice game, based on main after Peach Panic. Also hides Cherry Empire fractional displays without changing internal accounting.
- Four empty plots, one 1 ATK / 1 DEF starter pear. Select a pear and click an empty plot to inherit both stats. Four stages; 180 seconds base maturity +12% per combined stat above 2. Only mature trees may be cut. Free 1:1 emergency seed if no trees or pears remain, no coin reward.
- Free watering refills ten minutes. Fertilizer costs five Star Coins per five minutes of 4x growth while watered; stacks without gameplay cap. Care supplies are consumed while growing/producing, not while mature and inventory full. Offline growth uses timestamp chunks and stops at supply or inventory limits.
- One fruit per 45 effective seconds (11.25 fertilized); 1 Star Coin on generation. Inventory starts at 40 slots; permanent +10 slot purchases start at 25 Star Coins and increase by 15 coins each level. A 1,000-slot storage safety limit bounds the single Firestore document and client render size. Existing saves migrate without losing pears. Independent mutations are uniform in hundredths from -0.50 to +0.50; minimum 1.00. Fractional attack, defense and combat HP are rounded to hundredths, with no changes to coin formulas. Plant, throw or discard fruit.
- Enemy unlocked on tree ATK or DEF >=2; boss at >=5. Unlocks persist. Enemies start 2/2/4 HP, scale linearly. Bosses start 5/5/18 HP, scale attack 1.28x, defense 1.25x, HP 1.32x per boss, rounded. No final opponent; numerical range limits practical progression (boss stats saturate at 1e12). Each throw consumes fruit; if pear DEF < enemy ATK or pear ATK <= enemy DEF, no damage; otherwise damage = pear ATK - enemy DEF. No opponent attacks you or your trees. Boss fully heals 30 seconds after first throw, regardless of later hits.
- Enemy drop = 5 + (ATK + DEF) * 0.25; boss = 10 + (ATK + DEF) * 0.5. Fractions stored internally, whole coins credited.
- Secret Pearlie: 1% per generated fruit after first boss. Fruiter: per fruit 1/10000 initially, multiplied by 1+0.25*bosses defeated, probability max 1. Permanent shared account ownership. No trophy requested.
- Illustrated growth stages, pear and monster art, contrast-safe buttons, fullscreen and audible toasts. Visible care projected locally; actual fruit and coins settle on actions or 30-second sync. Closed/hidden tabs do not poll. Server owns state, atomic wallet version preconditions protect fertilizer debit and payouts, same request ID retries return saved result. No new rules, Worker, Blaze, secrets or paid jobs.
- Run `node --test workers/cd-store/tests/giving-tree.test.mjs`; deploy existing Worker `cd workers/cd-store && npx wrangler deploy --config wrangler.live.toml`. Browser, actual Firestore and production quota testing pending.

- Fullscreen compact layout: garden, battle grove and inventory occupy three adjacent columns on desktop, with a compact header, smaller tree/monster art and small pear tiles. Fullscreen panels fit the viewport; exceptionally short windows or unusually large stats can scroll within a panel. Narrow screens place inventory first and allow normal vertical scrolling. No backend changes.

- Cut tree and discard pear use red two-click confirmation buttons with eight-second expiration instead of native dialogs, preserving fullscreen. Decimal genetics and formatting are unchanged.

- Inventory management: ordinary clicks toggle multi-selection. Sort by newest, attack, defense or combined total (descending). Bulk discard and clear all confirm the exact displayed IDs in one server action, preserving any newly generated pears during the request. No-pear/no-tree recovery seed still applies. Deselect all is local only. Planting and throwing remain one pear per action. No extra rules.

Preserve inventory scroll position on selection/sync; sorting returns to top. Empty inventory message distinguishes no fruit from hidden tiles. Frontend only.
