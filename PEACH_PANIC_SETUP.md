
# Peach Panic
Third game in Fruity Paradice, from main after Cherry Empire.
- 30-second round, 52 peaches scheduled every 500ms on 12 non-overlapping positions. Growth takes 2.8–3.8 seconds. Each peach expires 1.4 seconds after peak ripeness.
- Original illustrated SVG orchard with animated clickable peach sprites, ripeness ring, color and size changes, golden perfect cue, blue marker, score popups, countdown, touch and keyboard-accessible fruit buttons. Normal board fits available viewport, fullscreen expands it; exceptionally short windows may scroll. Fullscreen fallback and audible toasts use existing shared notification system.
- Timing within ±150ms awards 5 points, ±350ms 4, ±650ms 3, ±1000ms 2, other sufficiently grown peaches 1. Too-early picks consume the peach for zero. Blue peaches appear with approximately 1/12 probability and double points. No new Star Coin payout was added because the request specified points and collectible rewards.
- Secret Peachiboo: 1/5 per blue peach picked, combined across a round. Fruiter: one roll per completed round at sqrt(score)/10000 for positive scores (1/10000 at score 1). No Fruiter roll at score zero. Shared permanent axolotl ownership, no public encounter claims. Both awarded at confirmed finish, not mid-round. Peach Panic Mastery at 240 points: perfect base score is 260 before blue bonuses; seeded tests include a strong imperfect run passing the threshold. Trophy has custom peach medallion artwork.
- Existing verified Live Firebase account and Worker. Server issues seeded schedule and start time, requires 30 seconds to elapse, replays unique timestamped picks, saves best score and awards collectibles atomically. No additional Worker, new secret, paid services or Firestore rules. Client sends state on initial load, then start and finish only per normal round. Browser stores in-progress picks locally for refresh/retry; a new round replaces an expired unsaved round. Server validation limits forged totals and duplicate rewards but cannot prove a human clicked at the reported time; deterministic schedules may be solved by bots.
- Run `node --test workers/cd-store/tests/peach-panic.test.mjs`. Deploy existing Worker: `cd workers/cd-store && npx wrangler deploy --config wrangler.live.toml`. Browser, fullscreen, actual Firestore and production CPU quota testing still required. Use preview with verified Live Firebase account.
