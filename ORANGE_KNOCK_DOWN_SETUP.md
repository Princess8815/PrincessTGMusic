# Orange Knock Down
Fifth Fruity Paradice game. Original illustrated slingshot orchard. Mouse/touch pull from the launcher or accessible angle/power controls. Fixed-step projectiles, destructible branches, falling oranges, increasing procedural orchard size and tougher branches. Sniper selects any remaining orange and always knocks it down.
- Marina has the level's free shot allowance (limited allowance scaled to structural durability). Aqualily splits into three; Bulky deals triple branch damage; Sploder bursts nearby branches/oranges; Sniper guarantees one orange. Specials are extra throws, three each once per account, 100 Star Coins for one additional use. Purchases persist; no refund on retry. 9,999 stored uses per type safety cap.
- Each newly cleared level earns 10 Star Coins once; free retries replenish only Marina. Procedural compact towers increase in height, material hardness and obstacle complexity; numerical level limit 1,000,000. Orange Knock Down Mastery trophy is awarded on completion of level 1,000, including existing qualifying accounts on their next load. Merely reaching the level does not qualify.
- Fruiter rolls on each completed level, 1/10,000 initially times (1+0.25*(level-1)), probability capped at 1. Tangie rolls 1% on completed levels 11 and later. Tangie is the new collection reward; launch types are game power-ups, not new profile collectibles.
- Existing trusted Worker, privateGames/orangeKnockDown, atomic wallet writes, revision preconditions and idempotent retry; no new rules. Browser submits only launch inputs; server reconstructs result. Predictable layouts and deterministic physics permit solver bots; not proof of human play. No periodic polling.
- Fullscreen, mobile controls, persistent progress and pending request recovery. Homepage title and Open Graph metadata changed to PrincessTG Creations.
- Run node --test workers/cd-store/tests/orange-knock-down.test.mjs. Deploy: cd workers/cd-store && npx wrangler deploy --config wrangler.live.toml.

- New levels use layout version 2: load-bearing supports, glass (3+), two-hit brick barricades (5+), stone (8+), indestructible reflective backstop (12+), steel (16+), angled reflectors and taller walls (20+). A lost support drops connected structures and their fruit. Existing saved version-1 levels finish using the legacy map, then advance to the new structure engine without losing inventory or rewards. The centered Next level button is inside the victory overlay.

- Layout version 3 rotates ten structural puzzle families and varies positions/materials by level and seed. Previous version 1/2 boards stay intact until next level. New milestones: spring bumpers level 24, reinforced alloy level 30, chain-reaction crates level 36. Feature progress uses confirmed highest level cleared, measured within the current milestone interval. Mystery silhouettes reveal names, color and explanations when unlocked; the win overlay shows the discovery or next progress. No additional requests or storage fields for unlocks.

- Layout version 4 adds gold horizontal trampolines at level 27. They boost descending shots upward with bounded speed and preserve forward motion, remain indestructible, and have their own mystery/reveal icon. Older maps keep their version until the next level. No change to coin or collectible rewards.

- Layout version 5 allows bounce pads at arbitrary angles with two-sided mirror reflection and a capped 1.35x speed boost (minimum 20, maximum 32). Level 27 introduces a slanted bank; later levels add relay and back-bank pads. Existing version 4 horizontal pads retain their original behavior and saved geometry until advancing. No changes to rewards.

- Fullscreen is arena-only: Back returns to the regular game menu without resetting the attempt. Compact read-only arena counters remain; feature cards, shop, sliders, help and other panels are hidden. The selected launcher is chosen outside fullscreen. The 16:9 board stays fully visible (letterboxed in portrait). Marina reaching zero while oranges remain ends the attempt on both client and server, regardless of spare special charges; retry restores the current level's Marina allowance only. Clearing the final orange with Marina's last throw still wins. No Firestore rule changes; redeploy the Worker for the updated loss rule.
