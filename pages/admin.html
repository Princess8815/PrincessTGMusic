    Products & shipping profiles
    

    Add merchandise and choose its packaging. Save drafts with Publish unchecked. Manage stock in Inventory.
    


    

    Shipping profiles
    

    


    

    

    Package length and width stay constant. Height and weight are the packaging base plus each item's added height/weight. Measure all supported quantities. For a fixed-size box containing one item, set max quantity to one.
    

    











    Fees do not automatically buy insurance or tracking. Only charge fees for services actually provided.
    


    

    Merchandise listings
    

    


    

    

    

    

    

    

    

    Find the correct tax code for this product before publishing.
    

    International customs (optional, domestic only if blank)
    Fill all fields only after verifying the actual country of origin, tariff code and net item weight.
    




    



    

    Customers must order items with different packaging profiles separately for now. Manage stock and processing time in Inventory below. No digital delivery.
    Inventory and order fulfillment
    Existing listings default to made to order, 2–3 business days. Available stock excludes reserved and sold units. Refunded stock must be restocked manually after inspection.
